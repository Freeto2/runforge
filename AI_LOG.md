# Отчет об использовании ИИ-инструментов (AI_LOG)

### 1. Инструменты и модели
В ходе выполнения тестового задания я использовал ИИ-ассистента **ChatGPT** на базе модели **GPT-6**. 
Инструмент применялся для генерации mock-данных и для тестирования и рефакторинга логики фильтрации.

### 2. Ключевые запросы и контекст
Для решения архитектурных задач ассистенту передавался контекст структуры компонентов React и модели данных (`Run`). 
Наиболее полезными оказались следующие запросы:



* **Запрос 1 (Синхронизация фильтров):** *"У меня есть массив объектов. Мне нужно сделать так, чтобы поиск по тексту и фильтрация по кнопкам-статусам работали одновременно, 
  не затирая исходный массив данных. Как это правильно реализовать в React?"*
  
* **Запрос 2 (Интеграционные тесты):** *"Как написать тест на Vitest + React Testing Library для проверки асинхронного сценария, когда первый запрос к серверу падает с ошибкой, на экране появляется кнопка 'Repeat', а при клике на нее происходит успешный повторный запрос данных?"*

### 3. Ошибки ИИ и их исправление
В процессе генерации кода ассистент предложил несколько неудачных решений, которые были вовремя замечены и исправлены:

1. **Мутация стейта:** Изначально ИИ предложил перезаписывать оригинальный массив `agents` через `.filter()` прямо внутри функций-обработчиков кнопок. Это приводило к тому, что при переключении статусов данные безвозвратно исчезали. Ошибка была исправлена переходом на паттерн производного состояния (Derived State) с вычислением отфильтрованного списка «на лету» внутри хука `useMemo`.
2. **Некорректная сортировка:** ИИ обернул числовое поле `durationSeconds` в конструктор `new Date()`, что ломало математическое вычитание при сортировке по длительности. Ошибка была исправлена прямым вычитанием чисел: `(a.durationSeconds || 0) - (b.durationSeconds || 0)`.
3. **Пропуски зависимостей:** В массиве зависимостей `useMemo` ассистент забыл указать сам массив данных `agents`, из-за чего интерфейс не обновлялся при первоначальном ответе от mock-сервиса. Зависимость была добавлена вручную.
