# Runforge — Панель управления запусками AI-агентов

Тестовое задание на позицию **Junior Frontend Developer**.  
Интерфейс для мониторинга запусков AI-агентов с возможностью фильтрации, поиска, сортировки и просмотра подробных логов.

## Стек технологий
* **React 19** (Functional Components, Hooks)
* **Vite 8** (Сборщик проекта)
* **Sass (SCSS)** (Стилизация)
* **Vitest & React Testing Library** (Интеграционное тестирование)
* **Oxlint** (Быстрый линтинг кода)

---

##  Инструкция по запуску

### 1. Установка зависимостей
Перед запуском убедитесь, что у вас установлена Node.js. Выполните команду в корне проекта:
```bash
npm install
```

### 2. Запуск приложения в режиме разработки
Для запуска локального сервера разработки (Vite) выполните:
```bash
npm run dev
```
После запуска приложение будет доступно по адресу, указанному в терминале (обычно `http://localhost:5173`).

### 3. Запуск тестов
Для запуска интеграционных тестов (сценарии поиска, комбинированной фильтрации и обработки ошибок):
```bash
npm run test
```

### 4. Проверка кода линтером
```bash
npm run lint
```

## Структура проекта

Код декомпозирован на модули в соответствии с принципами разделения ответственности (Separation of Concerns):

```text
src/
├── components/
│   ├── agents/
│   │   ├── agent-details.jsx   # Компонент отображения подробных логов и деталей запуска
│   │   ├── agent-item.jsx      # Карточка / строка отдельного запуска агента
│   │   ├── filter-bar.jsx      # Изолированная панель управления (поиск, фильтры, сортировка)
│   │   └── agents-list.jsx     # Главный контейнер страницы Runs (управление стейтом)
│   │
│   └── UI/                     # Переиспользуемые атомарные UI-компоненты
│       ├── Button.jsx          # Кастомная кнопка с поддержкой стилей и состояний
│       ├── Input.jsx           # Кастомное текстовое поле ввода
│       ├── Select.jsx          # Компонент выпадающего списка для сортировки
│       └── Modal.jsx           # Модальное окно (используется для деталей)
│
├── data/
│   └── agents.js               # Локальный mock-сервис (имитация асинхронных Promise-запросов)
│
├── utils/
│   └── url.js                  # Вспомогательные утилиты для работы с URLSearchParams
│
├── App.jsx                     # Корневой компонент приложения
└── main.jsx                    # Точка входа приложения
```

## Реализованный функционал & Особенности

1. **Комбинированная фильтрация (useMemo):** Поиск по названию/репозиторию и фильтрация по кнопкам статусов работают одновременно, дописывая параметры друг друга и не мутируя исходный массив данных.
2. **URL-фильтры (Бонус):** Все параметры состояния (`search`, `status`, `sort`) автоматически синхронизируются с адресной строкой браузера. При обновлении страницы (F5) состояние полностью восстанавливается.
3. **Обработка Edge Cases:** Реализованы экраны загрузки (`Loading...`), пустых результатов поиска (`Nothing found...`) с кнопкой сброса, а также симуляция падения сети (`Failed to load data`) с рабочей кнопкой `Repeat` для повторного запроса.
4. **Интеграционные тесты:** Написаны тесты на Vitest для проверки асинхронного поведения интерфейса при обработке ошибок и успешного повторного рендеринга данных.
